      Questions fréquentes

      Vous vous demandez peut-être…

      Les participants doivent-ils créer un compte ?

      Non. Ils ouvrent le lien ou scannent le code QR, saisissent le code de la séance et un pseudo, et répondent depuis leur téléphone, leur tablette ou leur ordinateur.

      Faut-il installer une application ?

      Non, La Ruche fonctionne dans le navigateur, pour l'animateur comme pour les participants.

      Puis-je réutiliser mes supports existants ?

      Oui : importez un document Word, PDF ou Markdown écrit dans un format simple (« QCM : question », puis les réponses en liste). Un modèle est fourni dans l'application.

      Les participants peuvent-ils répondre à distance, sur plusieurs jours ?

      Oui, avec le rythme autonome : la séance reste ouverte et chacun répond quand il veut. Vous consultez les résultats à tout moment.

      Comment l'intégrer à ma présentation PowerPoint ?

      Un bouton génère une diapositive d'invitation (code de la séance et code QR) à insérer dans votre présentation.

      Où sont stockées les données ?

      Les projets et les réponses sont stockés chez Google Firebase. Les participants ne donnent ni nom ni e-mail : seulement un pseudo de leur choix.

      Comment vous contacter ?

      Une adresse de contact sera bientôt publiée ici. En attendant, ouvrez l'application et créez votre compte animateur : c'est gratuit.
